# Страницы врачей BREORIS MEDICAL

## Сделано
10 профилей и каталог на украинском, общий шаблон и JSON-источник данных. Карточки этих врачей на главной ведут на профили. Остальные четыре существующие карточки сохранены. Название кнопок записи унифицировано. Анимация главной не менялась.

Структура повторяет порядок референса Helyos: крошки, фото, ФИО и «Лікар», характеристики, дополнительные профессиональные разделы, запись, отзывы. Разделы без подтверждённых данных скрываются. Ссылки лечения создаются только для существующих локальных страниц. На мобильном контакты располагаются перед фото.

## Подключение форм
В `dist/doctor-pages-config.js` задаются bookingEndpoint, reviewEndpoint и необязательный onAnalyticsEvent. Сейчас endpoints пустые: реальные заявки и отзывы НЕ отправляются, сайт показывает честное сообщение и телефон.

POST JSON записи: {name, phone, doctorId, branchId}. Успешный ответ: {"accepted":true}.
POST JSON отзыва: {name, doctorId, rating, text}. Успех: {"accepted":true,"moderationStatus":"pending"}.
Нужен сервер, который принимает заявки и сохраняет отзывы в очередь модерации. Публикация отзывов только после ручного одобрения на сервере. Этот сервер и панель модератора в текущем статическом проекте отсутствуют. Сервер должен валидировать поля, ограничивать частоту запросов и разрешать CORS для домена сайта. Используйте HTTPS; HTTP разрешён только для localhost при разработке.

Аналитика: событие окна `breoris:analytics` с event booking_click/phone_click, doctorId и path. Контактные данные в события не передаются. Можно подключить собственный обработчик через конфигурацию.

## SEO
Уникальные title/description, canonical, Open Graph, Person + MedicalClinic и хлебные крошки. Неизвестный стаж не вставляется в SEO. Сторонний рейтинг выводится ссылкой, не объявляется собственным рейтингом сайта. Sitemap содержит главную, каталог и 10 профилей. Существующий режим приватного превью noindex,nofollow сохранён; перед публичным запуском нужно подтвердить домен и разрешить индексацию.
